ANALYSIS PLAN: INVESTIGATION OF POTENTIAL CAUSES OF CHIP FAILURE


OVERVIEW

Since we currently do not have examples of failed chips, the analysis cannot directly compare failed versus successful chips or build a failure prediction model. Instead, the purpose of this analysis is to identify process conditions, manufacturing steps, and measurement variables that may contribute to future chip failure.

The analysis will focus on identifying:

- Sources of process variation
- Manufacturing steps with high inconsistency
- Metrics that strongly relate to each other
- Metrics with unusual behaviour or extreme values
- Areas where process improvements could reduce failure risk

The manufacturing process will be separated into two main areas:

1. PEL (Process Enrichment Layer)
2. Immobilisation


PEL is largely automated, meaning the likelihood of human-induced variation is reduced. However, automation-related issues, reagent variation, equipment drift, or unexpected process deviations may still contribute to chip quality issues.

Immobilisation is considered the most likely area where improvements may be found because this stage is not fully automated. Human involvement introduces possible variation through:

- Timing differences
- Pipetting variation
- Manual handling differences
- Reagent preparation variation
- Environmental exposure

Therefore, although all process stages will be analysed, immobilisation metrics will receive additional focus when identifying potential failure mechanisms.



STEP 1: DATASET CONSTRUCTION AND DATA INTEGRATION


The first step is to create one complete analysis dataset containing all available process measurements.

The purpose is to ensure that every possible variable that could influence chip performance is available for statistical analysis.


1.1 PEL PROCESS METRICS

Include:

- All individual PEL process steps
- Raw measurement values
- Changes between consecutive PEL steps

Calculated variables should also be created and stored.

Examples:

- Change between steps
- Step-to-step variation


1.2 IMMOBILISATION PROCESS METRICS

Include:

- Individual immobilisation flags
- Combined immobilisation reagent steps
- Immediate immobilisation measurements
- 5 second average immobilisation measurements


Both immediate and 5 second average values should be analysed separately.

Reason:

Immediate measurements capture the initial response.

5 second averages reduce noise and represent overall process behaviour.


Calculated metrics should include:

- Mean response
- Median response
- Standard deviation
- Percentage coefficient of variation (%CV)
- Range
- Difference between steps
- Percentage change between steps


1.3 STANDARD CURVE VARIABLES

Include all important standard curve information.

Variables:

- Curve type (4PL or 5PL)
- PL parameters
- R squared value
- X values
- Y values


Include:

4PL parameters:

- Top asymptote
- Bottom asymptote
- Slope
- EC50/inflexion point


5PL parameters:

- Top asymptote
- Bottom asymptote
- Slope
- EC50/inflexion point
- Asymmetry factor


Also calculate additional variables where possible:

- Predicted signal from curve
- Residual error
- Difference between observed and fitted values


Calculated values should be stored instead of only relying on reported values.


1.4 DATASET SPLITS

The final dataset should be separated into different analysis formats:

Overall dataset:

Includes all chips together.

Chip-level dataset:

Each chip analysed individually.


Different versions should also be created:

- Immediate immobilisation data
- 5 second average immobilisation data
- Individual process flags
- Combined reagent steps
- Raw values
- Calculated values



1.5 REMOVE REDUNDANT VARIABLES


CHANNEL 2 REMOVAL

Channel 2 should initially be removed from the main analysis.

Reason:

- It is not currently used independently
- It does not represent a separate failure mechanism
- It increases dataset complexity
- It may artificially increase correlations

Channel 2 can be analysed separately in future once its independent relevance is established.


REMOVING SIMILAR VARIABLES

Variables measuring the same property should not all be included.

Examples:

Mean vs Median:

Keep one.

Decision:

If data is normally distributed:
Use mean.

If data is skewed or contains outliers:
Use median.


Variation metrics:

Choose between:

- Standard deviation
- %CV


Recommendation:

Use %CV when comparing different signal levels.

Use standard deviation when analysing absolute variation.


STEP 2: EXPLORATORY DATA ANALYSIS


The first analysis stage is to understand how each metric behaves across all chips.


2.1 DISTRIBUTION ANALYSIS

For each metric generate:

- Box plots
- Histograms
- Summary statistics


Summary statistics:

- Mean
- Median
- Standard deviation
- Minimum
- Maximum
- Interquartile range


Purpose:

Identify:

- Stable process steps
- Highly variable process steps
- Outlier chips
- Potential problem areas


Interpretation:

High variability:

May indicate:

- Poor process control
- Sensitivity to manufacturing variation
- Increased failure risk


Low variability:

May indicate:

- Stable controlled process
- Lower likelihood of causing failures


2.2 CHIP LEVEL ANALYSIS


Analyse each chip individually.

Calculate:

- Average response
- Difference from population average
- Number of extreme measurements
- Overall consistency


Identify chips with:

- Unusual immobilisation behaviour
- Abnormal PEL behaviour
- Poor standard curve characteristics


Although failed chips are unavailable, these chips may represent higher-risk manufacturing examples.


STEP 3: CORRELATION ANALYSIS


Correlation analysis will identify relationships between process variables.


3.1 CREATE CORRELATION MATRICES


Generate correlation tables for:


PEL variables:

- Raw PEL steps
- PEL step changes
- Variation metrics


Immobilisation variables:

- Individual immobilisation steps
- Combined reagent steps
- Immediate measurements
- 5 second averages


Standard curve variables:

- PL parameters
- R squared
- Curve characteristics


3.2 HIGH POSITIVE CORRELATIONS


Investigate strong positive correlations.

Important thresholds:

0.7 - 0.9:
Strong relationship

Above 0.9:
Potential duplicate information


Questions:

- Are multiple measurements describing the same process?
- Is one manufacturing step driving another?
- Can variables be reduced?


Example:

If immobilisation step 3 strongly correlates with poor R squared values:

Possible interpretation:

Variation during immobilisation may affect final chip quality.


3.3 HIGH NEGATIVE CORRELATIONS


Investigate negative relationships.

Examples:

High immobilisation response associated with:

- Lower R squared
- Poor curve fitting
- Abnormal standard curve parameters


Possible causes:

- Excess reagent activity
- Surface chemistry imbalance
- Over immobilisation


3.4 LOW CORRELATION VARIABLES


Low correlation does not mean unimportant.

Focus on variables with:

- Low correlation with most variables
- High variation between chips


These may represent independent sources of variation.

Example:

A process step with high variability but low correlation may represent an uncontrolled manufacturing factor.


STEP 4: PROCESS VARIABILITY RANKING


Create a ranking system to identify the highest risk process variables.


Each metric should be scored based on:


1. Variation score

Based on:

- %CV
- Standard deviation
- Interquartile range


2. Correlation score

Based on:

- Number of strong correlations
- Relationship with performance indicators


3. Outlier score

Based on:

- Number of chips outside expected limits


Combine these scores to produce an overall process risk ranking.


Example:

High risk metric:

- High variability
- Strong relationship with performance
- Frequent outliers


Low risk metric:

- Stable
- Low variation
- No relationship with performance


STEP 5: RELATING PROCESS VARIABLES TO CHIP PERFORMANCE


Identify output indicators representing chip quality.

Potential outputs:

Standard curve quality:

- Low R squared
- Poor curve fitting
- Abnormal PL parameters


Signal performance:

- Low signal
- High variation
- Unexpected response changes


Investigate:

Which manufacturing variables are associated with poor performance indicators?


STEP 6: MULTIVARIATE ANALYSIS


After identifying important variables, perform analysis using multiple variables together.


6.1 PRINCIPAL COMPONENT ANALYSIS (PCA)


Purpose:

Determine whether chips naturally separate based on process behaviour.


Questions:

- Do chips group into different manufacturing patterns?
- Are there clusters of unusual chips?
- Are immobilisation variables driving separation?


Potential outcome:

Identify:

- Normal chip behaviour
- High variation chips
- Potential risk groups



6.2 CLUSTERING ANALYSIS


Use:

- Hierarchical clustering
- K-means clustering


Purpose:

Identify groups of chips with similar manufacturing characteristics.


Example:


Cluster 1:

Stable PEL + stable immobilisation


Cluster 2:

Stable PEL + high immobilisation variation


Cluster 3:

Poor standard curve performance



STEP 7: PROCESS SEQUENCE ANALYSIS


Because chip manufacturing occurs sequentially, investigate whether variation propagates through the process.


Analyse relationships:

PEL changes → Immobilisation behaviour

Immobilisation behaviour → Standard curve quality


Questions:

- Does early variation affect later steps?
- Does variation increase throughout manufacturing?
- Is there a specific point where instability begins?



STEP 8: IDENTIFY PROCESS IMPROVEMENT OPPORTUNITIES


Based on results:


If PEL variation is low:

- Continue current automated process
- Focus improvement elsewhere


If immobilisation variation is high:

Investigate:

- Automation opportunities
- Improved timing control
- Operator training
- Reagent handling procedures
- Environmental controls


If certain steps strongly relate to poor chip performance:

Consider:

- Additional process monitoring
- Quality control checks
- Acceptance limits



FINAL OUTPUTS


The analysis should produce:


1. Clean analysis dataset

Containing:

- All process metrics
- Calculated variables
- Reduced redundant variables


2. Distribution analysis

Including:

- Box plots
- Summary statistics


3. Correlation analysis

Including:

- Correlation matrices
- High correlation investigation
- Low correlation investigation


4. Process risk ranking

Identifying:

- Most variable process steps
- Highest risk metrics


5. Chip grouping analysis

Including:

- PCA
- Clustering


6. Manufacturing recommendations

Identifying:

- Steps requiring further investigation
- Possible automation opportunities
- Process control improvements


OVERALL ANALYSIS OBJECTIVE


The objective is to identify process variables that may contribute to future chip failure by determining:

- Where variation occurs
- Which manufacturing steps are least controlled
- Which variables influence chip performance
- Which stages provide the greatest opportunity for improvement


The main hypothesis is that immobilisation-related variation is more likely to contribute to chip failure due to remaining manual intervention. However, the analysis will objectively evaluate all available process variables to determine whether this assumption is supported by the data.
